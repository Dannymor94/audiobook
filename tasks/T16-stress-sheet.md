## Зачем
Одна проверка на слух на словоформу вместо прослушки каждого вхождения.

## Сделать (код — на Mac, рендер — на gamebox)
1. Подкоманда `stress-sheet --batch K`: берёт K-ю порцию по 100 форм из
   `out/stress/risk.tsv`; каждая форма рендерится в своём «самом коротком предложении»
   из risk.tsv, текущий конфиг, 2 фиксированных seed. Сборка — механизм `pron-test`.
2. Один mp3 на порцию + `index.tsv` (позиция м:сс, форма, seed, предложение).
3. Страница отметок (по образцу страницы решений): по каждой форме — «ок» / «плохо»;
   кнопка «Скачать» → `stress_review_K.json`.
4. `stress-sheet apply <json>`: «ок» → `text/stress_verified.yaml` (форма, дата, seeds);
   «плохо» → `out/stress/failed.tsv` (дальше — тест вариантов через `pron-test`).
   `pronounce.yaml` не трогать.

## Правила
Те же, что в G04. Рендерить только порцию, разрешённую в сообщении человека.
Оценка: ~100 форм × 2 seed ≈ 200 коротких рендеров ≈ 50 мин на порцию — сообщить
точное время после первой порции.
