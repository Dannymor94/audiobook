# Инструкция по прослушке: Глава 1

**Тип:** инструкция владельца. Текст книги, голос, wav-файлы — не в git.
**Когда:** после того как Ryzen отрендерил главу, qa + assemble + master прошли, section.mp3 существует.

---

## Что нужно проверить при прослушке

Три класса ошибок, которые ловит человек (CER-прогон ловит пропущенные слова, не это):

1. **Ударение** — неверное ударение, которого нет в `pronounce.yaml`. Пример: «Оотзывы» вместо «Отзывы».
2. **Акцент / просодия** — неестественный ритм, странная интонация в конце фразы, слишком ровное или слишком монотонное прочтение.
3. **Артефакт** — щелчок, обрыв, резкое начало или конец фрагмента.

---

## Шаг 1 — Создать план прослушки на gamebox

```bash
# Узнать slug главы 1 (первый синтезируемый раздел после вступлений):
./run.sh status | grep -v skip | head -5

# Поставить имя в переменную, например:
export S=07_glava_1_nazvanie_razdela   # заменить на реальный slug

./run.sh listen-plan --section $S --random 10
```

Вывод: `план прослушки: N фрагментов, M:SS` и путь `out/listen/plan.mp3`.

---

## Шаг 2 — Перенести на Mac

```bash
# На Mac:
scripts/mac/fetch_results.sh gamebox --with-wav listen
```

Файлы в `~/Downloads/audiobook/<ГГГГ-ММ-ДД>/listen/`:
- `plan.mp3` — все фрагменты подряд, 0.8 с между ними
- `index.tsv` — оглавление: время, секция, чанк, теги, текст
- `review.html` — интерактивная страница разметки
- `chunks/*.wav` — отдельные wav для каждого фрагмента

---

## Шаг 3 — Прослушать и разметить

Открыть `review.html` двойным кликом (работает офлайн, без интернета).

Для каждого фрагмента:
- **хорошо** — всё в порядке
- **плохо** — есть дефект. Выбрать в выпадающем меню: *ударение / акцент / каша / темп / артефакт / другое*. В поле «комментарий» — что именно: «ударение на первом слоге», «резкое начало», «слишком быстро».
- **?** — не уверен, переслушать позже

Подсказки к тегам в оглавлении:
- `начало` — первые 30 с главы
- `подозр: слово` — CER-подозрения по конкретному слову
- `выборка` — случайная проба

---

## Шаг 4 — Экспортировать и импортировать разметку

На странице: **«Скачать разметку»** → сохраняет `labels_<название>_<id>.json`.

Если кнопка не работает (file://): **«Копировать JSON»** → вставить в файл.

```bash
# На gamebox (или Mac, если журнал там):
./run.sh labels import ~/Downloads/audiobook/<ГГГГ-ММ-ДД>/listen/labels_*.json
# → "добавлено N, уже были M, без оценки K"

./run.sh labels show --section $S   # проверка: таблица с оценками
```

---

## Шаг 5 — Построить план исправлений

```bash
./run.sh fix plan --journal   # читает text/labels.yaml
# вывод: список чанков с "плохо", отсортированных по манифесту
```

Если план не пуст:
```bash
./run.sh fix queue            # поставить redo в очередь (по 3 кандидата)
./run.sh queue run            # выполнить
./run.sh fix review           # страница выбора кандидата

# После прослушки страницы выбрать лучший вариант:
./run.sh accept $S <chunk_id> <N>   # N — номер варианта
```

---

## Шаг 6 — Исправить ударения

Если проблема — ударение, его правят **не переозвучкой, а словарём**:

```bash
# Открыть text/pronounce.yaml и добавить строку по правилу:
# - ключ: слово в том регистре, в каком оно стоит в тексте чанка
# - значение: слово с ударением (одна заглавная ударная гласная: волнУ, ЗапИть)
# - исключение — ударение на первой букве уже-заглавного: Оотзывы
```

После правки `pronounce.yaml`:
```bash
./run.sh chunk --section $S   # 0 queued — хеши пересчитаны, wav не тронуты
./run.sh synth --section $S   # только затронутые чанки
./run.sh assemble --section $S
./run.sh master --section $S
```

## Итого: что приносит один сеанс прослушки

| Команда на gamebox | Результат |
|---|---|
| `listen-plan --section $S` | `out/listen/plan.mp3` + `index.tsv` |
| `fetch_results.sh --with-wav listen` | Файлы на Mac |
| *(разметка в браузере)* | `labels_*.json` |
| `labels import` | Запись в `text/labels.yaml` |
| `fix plan --journal` | `out/fix/plan.json` |
| `fix queue` + `queue run` | Новые кандидаты в `out/redo/` |
| `fix review` → `accept` | Принятый вариант |
| `assemble` + `master` | Обновлённый `section.mp3` |

**Ориентир:** 56 чанков главы × ~3 с на фрагмент = ~3 минуты прослушки на одну главу (с выборкой из 10 фрагментов, `--random 10`). Первый сеанс лучше слушать целиком (`plan.mp3`) перед разметкой.
