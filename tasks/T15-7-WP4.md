**A4. C3 authoritative ledger and merge:**

- `stress_gold.archive.tsv` is derived from stale rows only, never authoritative; independently rebuild atomically. Interrupted export rebuild does not invalidate complete authoritative gold. Interrupted temp is ignored.
- Mandatory synthetic end-to-end oracle: initial active gold → edit neighbor → old becomes STALE → todo contains same source_key → corrected label merged as NEW active version → original retained and archived → future scorer uses only new current version → second merge byte-identical; partial crash before/after rename always leaves valid complete ledger.
