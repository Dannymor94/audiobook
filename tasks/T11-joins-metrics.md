## Зачем
Главная жалоба на слух — интонация на стыках чанков. Сейчас стыки не меряет ничего.
Внутри абзацев ~1000 стыков (между абзацами пауза 900 мс и сброс естественный).

## Сделать
Новый модуль `src/audiobook/joins.py` + подкоманда `joins --section S`. Для каждой
пары соседних чанков **внутри абзаца** (определи по разметке чанкера, не по числу мс):
- медиана F0 последних / первых 0.5 с озвученного, разница в полутонах;
- наклон F0 в последних 0.5 с чанка i (полутон/с) — «точка вместо запятой»;
- темп каждого чанка: символы / озвученная длительность, разница в %;
- RMS хвоста и головы, разница в дБ.
F0 — `librosa.yin` с параметрами как в `ref_scout._f0` (librosa уже в uv.lock).
Вывод: `out/sections/S/<stem>.joins.tsv` (m:ss стыка, id пары, значения, флаги) и
топ-20 в консоль. Пороги — `qc.joins` в config.yaml (стартовые значения условные,
калибруются в G16); в хеш не входят — проверь. Если T10 уже влита — флаг
`fall_on_open_end` для `open_end`-чанков.
`suspects.py` не трогать (владелец T08), интеграция — отдельной задачей.
Тесты слоя 1: синтетические wav (тон с известной частотой и скачком) в tmp_path.

## Отчёт

Реализован модуль `src/audiobook/joins.py` и подкоманда `./run.sh joins --section S [--first N]`.

**Что сделано:**
- `_within_para_pairs` — определяет пары чанков внутри абзаца через `build_chunks` +
  отслеживание `unit_idx` по каждому элементу разметки чанкера (`kind == "text"`,
  не по числу мс).
- Метрики на каждую пару:
  - медиана F0 хвоста / головы в полутонах, разница (`f0_diff_st`)
  - наклон F0 в хвосте чанка i (`slope_tail_st_s`, ст/с) — маркер «точки вместо запятой»
  - RMS хвоста и головы в дБ, разница (`rms_diff_db`)
  - темп каждого чанка (символы / озвученная длительность), разница в %
- F0 — `librosa.yin` с теми же параметрами, что `ref_scout._f0`
  (fmin=65, fmax=320, frame=1024, hop=256), SR=24 кГц (прямо из синтеза, без конвертации).
- Тихие кадры маскируются по RMS (< 0.3 × медиана) до того, как считается F0.
- Пороги — `qc.joins` в `config.yaml` (стартовые значения; не входят в хеш чанков).
- Флаги: `F0_JUMP`, `FALL_END`, `RMS_JUMP`, `TEMPO_DIFF`.
- Вывод: `out/sections/S/section.joins.tsv` (14 столбцов) + топ-20 в консоль.
- T10 не влита → флаг `fall_on_open_end` не добавлен (условие в задаче выполнено).
- `suspects.py` не тронут.

**Тесты слоя 1** (`tests/test_joins.py`, 13 тестов):
- синусоиды с известной частотой → проверка медианы F0 в ст
- октавный скачок → `f0_diff ~12 ст`
- нарастающий/спадающий тон → знак наклона
- ½ амплитуды → -6 дБ
- `_join_row` на тех же синусоидах
- флаги вручную с граничными значениями
- `_within_para_pairs` на минимальных списках units: один длинный абзац, заголовок, два коротких абзаца
