## Зачем

1. `find_temperature` берёт **самый свежий** `out/golden/compare_*` по mtime — если есть
   несколько сравнений (в том числе в обратном порядке), страница покажет не то.
2. Теги разбираются `partition("_")` из имени папки — тег с «_» ломает соответствие A/B.

2. Теги A/B брать из метаданных сравнения (если `golden compare` их не пишет — писать
   `compare.json` с `{"A": tag, "B": tag}` в `golden.py`), не из имени папки.
3. У каждого плеера подпись — настоящая температура («0.9» / «1.0»), а не A/B.
4. Тесты слоя 1: тег с «_», две папки compare, обратный порядок.
