# AGENTS.md

Файл для Codex и любых агентов, кроме Claude Code (тот читает CLAUDE.md сам).

1. Прочитай `CLAUDE.md` целиком — это обязательные правила проекта. Они действуют и для тебя.
2. Доска задач и протокол: `tasks/README.md`. Бери только задачи с `agent: codex`
   (или без поля `agent`), у которых все `depends_on` в `done`.
3. `owner:` при взятии — `codex-<модель>`.
4. Перед сдачей: `uv run pytest -q` зелёный. В `main` не пушить никогда.

## Обязательное правило размещения вычислений

CLOUD-FIRST из `CLAUDE.md` применяется ко всем агентам: публичные тесты допускаются через отдельный проверенный облачный runner; существующие production/local guards остаются Gamebox-only. Приватные данные остаются локально до отдельного разрешения. Бюджет 0 USD, без обхода квот/guards. План: `tasks/T-CLOUD-FIRST-COMPUTE.md`.


Обязательный контракт квот и жизненного цикла облачных задач: `tasks/T-CLOUD-QUOTA-01.md`. Новые отправки GPU заблокированы до реализации и проверки долговременного резервирования; неизвестный статус удалённой задачи не разрешает повторную отправку.
