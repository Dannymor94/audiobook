# AGENTS.md

Файл для Codex и любых агентов, кроме Claude Code (тот читает CLAUDE.md сам).

1. Прочитай `CLAUDE.md` целиком — это обязательные правила проекта. Они действуют и для тебя.
2. Доска задач и протокол: `tasks/README.md`. Бери только задачи с `agent: codex`
   (или без поля `agent`), у которых все `depends_on` в `done`.
3. `owner:` при взятии — `codex-<модель>`.
4. Перед сдачей: `uv run pytest -q` зелёный. В `main` не пушить никогда.

## Обязательное правило размещения вычислений

GAMEBOX-FIRST из `CLAUDE.md` применяется ко всем агентам и всем задачам: реальный TTS только на подтверждённом gamebox, включая одиночные пробы и прямые скрипты. Перед загрузкой модели — проверка хоста, ресурсов и общего lock. Если предохранитель отсутствует или проверка не проходит — BLOCKED / GAMEBOX_REQUIRED. Никакого автоматического fallback на Mac или облако.
